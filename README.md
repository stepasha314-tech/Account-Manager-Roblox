# Account-Manager-Roblox
Application that allows you to manage multiple Roblox accounts in one place, letting you easily switch between your main and alt accounts without the hassle of constantly logging in and out.
Perfect for games that require grinding, storing in-game items or currency across multiple accounts, or simply keeping all your accounts organized and accessible in one spot.
Feel free to modify the code and submit pull requests if you think it will improve the project.
Multiple Roblox Instances support is included but must be enabled manually in the settings.
Found a bug? Report it in the issues section or reach out to us directly via Discord.
# WARNING
If anyone asks you to generate an account link, DO NOT do it. These links can be used to access your account without your permission and perform actions such as spending your Robux or doing things that could result in your account being banned. USE THESE FEATURES AT YOUR OWN RISK.

# Frequently Asked Questions
Q: Why is this program flagged as a virus?
A: Open source applications like this one are sometimes flagged by antivirus software because they share libraries with actual malware. The source code is fully available for anyone to inspect. You can also compile it yourself using Visual Studio which is completely free.
Q: How do I enable multiple Roblox instances?
A: Open the settings menu by clicking the gear icon in the top right corner. Under the General tab you will find the Multi Roblox option. Make sure Roblox is fully closed before enabling it.

Q: Why is multi-instance disabled by default?
A: Running multiple Roblox clients at once may be considered suspicious behavior by Roblox's anti-cheat system. For this reason the feature is disabled by default and must be enabled manually at your own risk.

Q: How do I back up my accounts?
A: Use the built-in decrypt tool and follow the provided instructions. You can then save the decrypted file to Google Drive, a USB drive or anywhere else you prefer. Note that this only works with files that originated from your own PC.
Q: Can I get banned for using this?
A: No. Account-Manager-Roblox does not violate Roblox Terms of Service. However some individual games may have their own rules regarding alt accounts so make sure to check before using it.
# Can I use this on Mac?
Unfortunately Account-Manager-Roblox is currently only available for Windows. Mac support may be added in the future.
# I found a bug. What should I do?
: Please report it in the bugs section with a detailed description and screenshots if possible. Make sure to click "Open Details" before taking a screenshot and write your report in English.
# My accounts show yellow or red dots. What does that mean?
Those dots indicate that the account has not been used in over 20 days. The longer it goes unused the more red the dot becomes. Simply log into a game with that account to remove the dot.

Q: I can't launch multiple accounts repeatedly.
A: This is caused by Roblox's own rate limiting system and is not something we can control.

Q: Adding an account doesn't work.
A: Try restarting the application. This issue will be addressed in the next update.
